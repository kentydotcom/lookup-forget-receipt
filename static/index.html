How it works

  • A public question goes in. Identity is not collected, and PII is refused.
  • Lookup is proxied through a Tavily or Firecrawl Sprites connector.
  • Notes stay on the Sprite at /notes/brief.md only.
  • On “Forget this.” the notes are wiped.
  • A deletion receipt (removed paths, leftover hash, timestamp) is filed via GitHub or S3 — not the notes themselves.

Shared rule: Sprite → Sprites connector / Fly gateway → provider. The raw token never lands on the box.
